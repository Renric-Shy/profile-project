Current Courses

Principles of building software systems: requirements, design, version control, testing and maintenance.

Process management, scheduling, memory management, concurrency and file systems.

Transmission media, signalling, protocols, network layering and error detection.

Discrete and continuous distributions, expectation, and elementary limit theorems.

MAT 353 — Operations Research

Linear programming, transportation models, decision theory, and network analysis.
